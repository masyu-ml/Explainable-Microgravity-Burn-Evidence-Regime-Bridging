# Security and Responsible Use

EMBER is an exploratory combustion research interface, not an operational spacecraft safety controller.

Do not upload or commit API secrets, authenticated NASA access credentials, private logs or personal information. Use a dedicated development environment and validate externally sourced data.

Potential security defects can be privately reported to the repository maintainer. Do not publish sensitive exploitation details in open issues.

Model applicability checks and scientific abstention support responsible research communication but do not replace formal software and physics validation.
